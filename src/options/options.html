Tab Out settings

Choose what sits at the top of your dashboard and how tabs get grouped.

Pinned sites

Always shown first on the dashboard. If a site has open tabs you get its normal card; if not, you get a click-to-open placeholder. Turning this off stops applying the list without deleting it — sites group by hostname like any other tab instead.

Disposable tabs

Tabs matching these rules are safe to close, because reopening them costs nothing — either a site's own homepage (Gmail inbox, X feed, GitHub front page), or a spent one-off page like the screen a Zoom meeting leaves behind once the call has already opened in the app. They're collected into one Disposable card, and count toward the dashboard's "Tidy up" button. Turning this off stops applying the rules without deleting them.

Path pattern: /j/* matches that path and everything under it · /home matches only that exact path · !#inbox/ excludes any URL containing that text · combine with commas, e.g. /*, !#inbox/ · leave blank to match only the site's root.

Custom groups

Merge several hostnames into one card, or split one site into separate cards by path. Rules are checked top to bottom — the first match wins.

Tab sorting

Whether your tabs should be reordered to match the dashboard automatically, or left alone until you click "Sort tabs" on the banner yourself.

History

How many recently closed tabs to remember. The oldest entries drop off automatically once you go over this limit. Reopening a tab, or a page you already have open, is never counted as history.
